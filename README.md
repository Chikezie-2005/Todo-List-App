# Python To-Do List App

A desktop To-Do List application built with Python and Tkinter.

## Features

- Add tasks
- Edit tasks
- Complete tasks
- Delete tasks
- Clear all tasks
- Automatic task saving
- Task counter
- JSON data storage

## Technologies

- Python
- Tkinter
- JSON

## How to Run

1. Clone the repository
2. Open the project folder
3. Run:

python todo_app.py
